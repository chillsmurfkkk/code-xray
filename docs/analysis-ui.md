# Аналіз — ЛР2, учасник B

Форми «Профілі», «Метрики», «Правила» й «Порушення» підключені до головного
вікна на базі `b6a7ade`. Відкрийте папку через «Код → Структура» й перейдіть
до «Аналізу». Завантажений знімок аналізується автоматично. Для демо:

```sh
./build/macos-gui/code-xray --demo
```

Профілі можна створювати, дублювати, імпортувати й зберігати у JSON. Помилковий
імпорт не змінює вибраний профіль. Метрики мають сортування, фільтр файла та
середнє/максимум з числовим знаменником; невідомі значення показуються окремо.
Пороги приймають цілі числа `0..INT64_MAX`. Зміна правил робить результат
застарілим; «Застосувати» повторює аналіз з копією профілю. Файли з диска
перечитуються при повторному відкритті папки.

«Перейти до коду» показує весь файл зі знімка, номери рядків, синтаксис C++
і діапазон функції через CodeView A. Пошук порушень поєднує правило, текст
і шлях. Помилка або скасування зберігають попередній результат.

## Інтеграція

- Сторінки B: `src/ui/analysis/`, namespace `xray::ui::analysis_pages`.
  Оформлення береться зі спільної теми; окремої палітри або стенда B немає.
- `MainWindow::setSnapshot` передає один ParsedSnapshot до «Структури» й B.
  Додавання в MainWindow і NavigationPanel лише підключають розділ аналізу.
- `AnalysisController` у `src/app/` запускає ядро B в QThread, передає прогрес
  у GUI й підтримує скасування. Заміна джерела скасовує стару задачу; її
  пізній результат не підміняє новий. Правки профілю не змінюють активну задачу.
- Переглядач A та делегат таблиць D використовуються без змін їхніх реалізацій.
  Парсер, Git, алгоритми метрик і review цим доповненням не змінені.

## Перевірка на macOS

Локальна збірка використовує вже встановлені Qt 6.11.2 і classic-пакети vcpkg:

```sh
cmake -S . -B build/macos-gui -G Ninja -DCODE_XRAY_QT_VERSION=6.11.2 \
  -DCMAKE_PREFIX_PATH="$HOME/dev/vcpkg/installed/arm64-osx;$(brew --prefix qt)"
cmake --build build/macos-gui
QT_QPA_PLATFORM=offscreen ctest --test-dir build/macos-gui --output-on-failure
./build/macos-gui/code-xray
```

2026-10-28, macOS arm64 / AppleClang 21 / SDK 26.5 / Qt 6.11.2:
**20/20 цілей CTest пройшли**, нативний `--demo --smoke-test` завершився з кодом 0.
Тести B перевіряють реальні C++ файли, усі чотири сторінки в головному вікні,
правила, навігацію, зміну теми, скасування та відкидання старої задачі.
Рендери обох тем і вузького вікна: `build/macos-gui/analysis-integrated/`.
Windows, нативні файлові діалоги та manifest-збірка з Qt 6.11.1 локально
не перевірялися. [Облік ЛР2](contributions/B.md).
