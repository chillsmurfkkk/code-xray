## Запуск тестів

Перший запуск зі стандартними `TEMP`/`TMP` sandbox пройшов 10 із 13 цілей.
`review` та `export` завершилися на записі файла, `profiles` — із повідомленням
`Cannot replace profile`. Для повторного запуску тимчасові файли спрямовано
в доступну папку під `build/` у робочому каталозі:

```powershell
$labTemp = Join-Path (Get-Location) 'build/lab1-verification-temp'
New-Item -ItemType Directory -Force -Path $labTemp | Out-Null
$env:TEMP = $labTemp
$env:TMP = $labTemp
ctest --preset windows-x64 --output-on-failure
```

Код і тести між запусками не змінювались. У доступному тимчасовому каталозі
**усі 13 цілей пройшли**, CTest повернув код 0. Це вказує на залежність першого
збою від тимчасового каталогу/обмежень середовища; обидва результати збережені.
