# Tree-sitter: ретроспектива інтеграції

Для розбору C++ я обрав Tree-sitter, тому що він швидкий, відносно простий в інтеграції та підтримує інкрементальний розбір. Для моєї задачі — навігації структурою коду — синтаксичне дерево добре підходить, а кількість залежностей менша, ніж у важчих рішень.

Tree-sitter будує синтаксичне дерево з вихідного тексту, але не дає готової моделі, потрібної Code Xray. Тому я налаштував парсер, реалізував обхід дерева й перетворення вузлів на власні сутності файлів, типів і функцій. Також я додав збереження діапазонів і формування діагностики, щоб програма могла показувати доступні результати навіть за наявності помилок синтаксису.

Найскладнішим для мене було розібратися зі структурою дерева та визначити, як інтерпретувати його вузли для потреб проєкту. Під час роботи я зрозумів, що Tree-sitter зручно використовувати для перетворення тексту коду на структуровану форму, з якою далі можуть працювати інші модулі програми.

Tree-sitter підтримує інкрементальний розбір, але поточна реалізація розбирає кожен файл знімка заново: попереднє дерево не передається парсеру. Повторне використання дерев між версіями файлів — можливе майбутнє покращення; для нього також потрібно визначати зміни й оновлювати власну модель сутностей.
