# Перевірка оформлення GUI

Дата перевірки оформлення: 2026-10-26. Цей журнал не змінює історичний
знімок і числові підсумки ЛР №1.

## Зміни

Спільний контур навігації, внутрішній роздільник, м'яка підкладка вибору,
панелі радіусом 16 і векторні іконки замінили окремі обведені блоки та
різнорідні стандартні значки. Кольори залишилися Gruvbox. Поверхні непрозорі,
із делікатним градієнтом; нативні ефекти скла й blur не використовуються.

`MainWindow` збирає `NavigationPanel` та `StructurePage`. Перший передає
`themeToggleRequested()`, другий поки показує стан до відкриття джерела.
Парсер, доменні контракти й координатор у цій зміні не змінювались.

Компоненти оформлення збираються в `xray_ui`; це спільна залежність застосунку
та GUI-перевірки. Для `NavigationPanel` увімкнено AUTOMOC, оскільки він має
власний Qt-сигнал і макрос `Q_OBJECT`.

## Відтворення

Windows x64, MSVC v143, Qt 6.11.1 Debug:

```powershell
cmake --build --preset windows-x64 --target gui_design_tests
$guiTestTemp = Join-Path (Get-Location) 'build/gui-design/temp'
New-Item -ItemType Directory -Force -Path $guiTestTemp | Out-Null
$env:TEMP = $guiTestTemp
$env:TMP = $guiTestTemp
ctest --preset windows-x64 --output-on-failure
```

Результат: **14/14 CTest пройшли**, зокрема `gui_design` та `gui_startup`.
Перенаправлення TEMP/TMP потрібне для обмеженого sandbox, як і в попередньому
журналі ЛР №1. У build залишаються попередження сторонньої inja та
`windeployqt` про відсутні каталоги перекладів; помилок збірки немає.

`gui_design` перевіряє:

- темну тему для нового сховища й збереження світлої в ізольованому QSettings;
- збереження поточного пункту та згорнутої навігації при зміні теми;
- збереження того самого read-only віджета коду;
- недоступність неготових сторінок;
- видимість обох областей після зміни розмірів splitter-а;
- повну висоту видимих багаторядкових підписів при вузькому вікні та шрифті +5 pt;
- розмір іконки при DPI 2× та оновлення раніше створеної іконки після зміни палітри.

Під час перевірки виправлено обрізання підпису: горизонтальне центрування
самого QLabel обмежувало його ширину без відповідного перерахунку висоти.
Тепер центрується текст, а ширину віджета визначає layout.

## Межі

Перевірка macOS Apple Silicon у цій сесії не виконувалась. Використано лише
кросплатформний Qt API, але повний preset і вигляд потрібно перевірити на Mac.
Тест на масштаб іконки 2× не є перевіркою на фізичному Retina-дисплеї.

Знімки ParsedSnapshot, пошук, фільтри, номери рядків і підсвічування синтаксису
ще не підключені. Це завершений прохід оформлення каркаса, а не приймання
повного еталона «Структура» або чотирьох форм A.
